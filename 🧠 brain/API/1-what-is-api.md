# What is an API?

## Simple Definition

==API== stands for **Application Programming Interface**.
It is a way **for two programs to talk to each other.**
One program sends a **request**. The other program sends back a **response**.

---
## A Simple Example

You use a weather app on your phone.
The app does not store weather data itself.
It calls a weather API. The API returns the weather data. The app shows it to you.

---
## Why Do We Use APIs?

- You do not need to build everything yourself.
- You can use other services (payment, maps, email, etc.).
- Different systems can work together even if they are written in different languages.
- You can hide internal logic. The caller only needs to know *what* to call, not *how* it works.

---
## Key Terms

| Term | Meaning |
|------|---------|
| Client | The one who sends the request |
| Server | The one who handles the request and sends a response |
| Endpoint | A specific URL or address you call |
| Request | The message the client sends |
| Response | The message the server sends back |
